## 🚀 About Me

I work across software development and technical project management, connecting web applications, backend services, data pipelines, and cloud infrastructure. I enjoy translating complex operational needs into practical software and bringing different parts of a system together.

My experience spans enterprise applications, integrations, automation, and applied AI, combining hands-on development with the coordination of projects across teams.

- **Backend & integrations** — Node.js services with Fastify and Express, Python APIs with FastAPI, real-time communication, and data exchange between business systems.
- **Web & mobile applications** — React and TypeScript interfaces, progressive web apps, reusable components, and React Native / Expo projects.
- **Automation & data** — ETL pipelines, scheduled processes, and tools that reduce repetitive work.
- **Cloud & infrastructure** — AWS and Azure environments, Terraform, Docker Compose, and Docker Swarm administration.
- **Monitoring & operations** — Zabbix administration and infrastructure monitoring.
- **Applied AI** — Natural language processing and projects involving computer vision and speech processing.
